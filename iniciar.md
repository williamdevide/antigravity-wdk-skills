# Antigravity WDK Skills
CLI para instalação de skills do ecossistema WDK, permitindo a expansão das capacidades de agentes de IA de forma padronizada.

## 🚀 Como Rodar Localmente

### Pré-requisitos
- Node.js 18+
- Git

### Passo a Passo via Terminal

1. **Instalar Dependências**
   ```bash
   npm install
   ```

2. **Testar o CLI**
   ```bash
   node cli.js
   ```

3. **Instalar uma Skill em um Projeto Local**
   ```bash
   node f:\antigravity\projetos\antigravity-wdk-skills-main\cli.js add criar-readme
   ```
