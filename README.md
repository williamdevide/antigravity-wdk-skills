## 🇧🇷 Português

### 📝 Descrição
Este repositório fornece uma suíte de habilidades (`skills`) de nível industrial projetadas para o framework Antigravity. Elas permitem que desenvolvedores automatizem tarefas repetitivas de documentação, deploy local e criação de apresentações interativas com um padrão de qualidade superior.

### 🚀 Novidades: Design Premium & Responsividade
O motor de apresentações interativas foi atualizado para o padrão **V3 Premium**:
- **Layout Lateral 35%**: Imagens laterais agora ocupam 35% reais da largura da tela no desktop, com um corte seco em diagonal invertida ultra-moderno.
- **Responsividade Total**: Slides adaptados para celulares, com empilhamento vertical inteligente (imagem no topo, texto abaixo) e rolagem fluida.
- **Performance**: Otimização de containers para evitar cortes de conteúdo em telas pequenas.

### 🚀 Instalação via NPX (WDK CLI)
Você pode instalar qualquer skill diretamente em seu projeto usando o CLI integrado:

```bash
# Instalar uma skill específica
npx github:williamdevide/antigravity-wdk-skills add <nome-da-skill>

# Instalar TODAS as skills de uma vez
npx github:williamdevide/antigravity-wdk-skills add all
```

## 🇺🇸 English

### 📝 Description
This repository provides an industrial-grade suite of skills designed for the Antigravity framework. They allow developers to automate repetitive documentation tasks, local deployment, and the creation of interactive presentations with a superior quality standard.

### 🚀 New Features: Premium Design & Responsiveness
The presentation engine has been updated to the **V3 Premium** standard:
- **35% Sidebar Layout**: Lateral images now occupy 35% of the screen width on desktop, featuring an ultra-modern inverted diagonal clean cut.
- **Full Responsiveness**: Slides adapted for mobile devices, with intelligent vertical stacking (image on top, text below) and smooth scrolling.
- **Performance**: Container optimization to prevent content clipping on small screens.

### 🚀 Installation via NPX
Install any skill directly into your project using the integrated CLI:

```bash

npx github:williamdevide/antigravity-wdk-skills add <skill-name>
```
