## 🇧🇷 Português

### 📝 Descrição
Este repositório fornece uma suíte de habilidades (`skills`) de nível industrial projetadas para o framework Antigravity. Elas permitem que desenvolvedores automatizem tarefas repetitivas de documentação, deploy local e criação de apresentações interativas com um padrão de qualidade superior.

### 🚀 Instalação via NPX (WDK CLI)
Você pode instalar qualquer skill diretamente em seu projeto usando o CLI integrado:

```bash
# Instalar uma skill específica
npx github:williamdevide/antigravity-wdk-skills add <nome-da-skill>

# Instalar TODAS as skills de uma vez
npx github:williamdevide/antigravity-wdk-skills add all
```

| Skill | Descrição | Comando |

| **criar-html** | Motor de apresentações interativas com UX fluida e design premium. | `add criar-html` |
