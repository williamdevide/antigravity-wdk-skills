# SKILL: criar-slidehtml (Fullpage Experience)

Esta skill permite a criação de apresentações interativas baseadas em HTML/CSS/JS, com navegação fluida estilo "Fullpage". Ideal para convocatórias, apresentações de impacto e dashboards interativos.

## 🚀 Funcionalidades Inclusas
- **Navegação Inteligente:** Suporte a teclado (setas, espaço), scroll do mouse (wheel) e cliques.
- **Clique Duplo:** Salto rápido para o primeiro slide (seta esquerda) ou último slide (seta direita).
- **Design System Nativo:** Suporte a cores dinâmicas, glassmorphism e animações de transição suave.
- **Responsividade:** Layout otimizado para diferentes resoluções.
- **Componentes Prontos:** Cards, Timelines agrupadas, Botões com efeito pulse e Barras de progresso.

## 🛠️ Como usar esta Skill

### 1. Inicialização
Solicite ao Antigravity para "Criar uma nova apresentação de slides usando a skill criar-slidehtml".

### 2. Estrutura Necessária
O projeto deve conter:
- `index.html`: Estrutura de containers e slides.
- `style.css`: Estilização das transições e componentes.
- `script.js`: Lógica de navegação.

### 3. Convenções de Código
- Cada slide deve ser uma `div` com a classe `.slide`.
- O container principal deve ter a classe `.slides-container`.
- Use a classe `.active` para identificar o slide visível.
